# Совместная работа над frontend:2–8 ноября 2026

## База для всех участников

Начинайте от актуального `main` после архитектурных изменений Курала и фиксируйте базовый SHA. Октябрьская `ui-fundation` и старый patch относятся к предыдущему этапу; они не содержат новую архитектуру 29 маршрутов.

Путь `/home/arcnosixta/GPA_calc` — проект на компьютере Курала. На другом компьютере используйте свою копию репозитория. Перед обновлением проверьте `git status`: чужие изменения не сбрасывайте и не перезаписывайте. Не переключайте ветки двум агентам в одном checkout; используйте отдельные клоны или согласованные worktree.

После получения актуального `main` создайте свою рабочую ветку в своей копии:

```bash
# Акылбек
git switch -c student-frontend main
```

```bash
# Койшыман
git switch -c management-frontend main
```

```bash
# Канат: только отчёты и доказательства
git switch -c qa-frontend main
```

Если рабочая ветка уже существует, продолжайте её после проверки базы; не создавайте и не сбрасывайте её повторно автоматически.

## Передача и приёмка

Участник передаёт перечень файлов, базовый/итоговый SHA, статус каждого экрана, результаты проверок и ограничения. Курал интегрирует изменения в `main`, сохраняя общую архитектуру. Публикация веток и PR — только по явному разрешению пользователя, сообщения другим людям автоматически не отправляем.

Канат проверяет текущую интегрированную версию и пишет отчёт в `docs/qa-week/**`; исправления делают владельцы. После исправления он повторяет сценарий и указывает новый SHA.

Цель до 8 ноября — законченный frontend на демоданных. Кнопки и формы должны давать заявленный локальный результат, а серверные операции, будущие этапы и реальные права не выдаются за работающие функции. Наличие 29 заголовков и ссылок само по себе не подтверждает готовность frontend.
