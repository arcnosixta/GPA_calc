# Совместная работа над frontend ScholarPath

Используйте актуальный `main` после обновления демосессии, ролевой навигации и геймификации. Зафиксируйте переданный Куралом SHA. На компьютере Курала репозиторий находится в `/home/arcnosixta/GPA_calc`. Каждый участник работает в своей копии или согласованном worktree и начинает с `git status`.

Создайте свою ветку от проверенного `main`. Если ветка уже существует, сначала сравните её базу с переданным SHA и сохраните рабочие изменения.

```bash
# Акылбек
git switch -c student-frontend main

# Койшыман
git switch -c management-frontend main

# Канат
git switch -c qa-frontend main
```

Используйте только команду для своей роли. `ui-fundation` хранит основу предыдущего этапа. Текущая карта URL и рабочая область описаны в [плане недели](frontend-week.md) и [UI-контракте](ui-contract.md).

Скопируйте промпт своей роли в чат Codex.

- Студенческие экраны, подключение GPA и UX аккаунта. [Промпт Акылбека](prompts/akylbek-week.md).
- Каталог, справочники, архив и роли пользователей. [Промпт Койшымана](prompts/koishyman-week.md).
- Чистый модуль GPA, тесты и QA интеграции. [Промпт Каната](prompts/qanat-week.md).

Канат передаёт контракт и коммит расчёта до подключения GPA в студенческом UI. Курал отвечает за общую демосессию, layout, навигацию и ролевые ограничения. Акылбек согласует с ним границы отдельной правки форм входа после студенческих задач. Койшыман передаёт запросы на изменение общих данных и реестра Куралу.

Передайте Куралу базовый и итоговый SHA, список файлов, результаты проверок и статус сценариев. Коммиты и описания пишем по-русски. В `main` изменения объединяет Курал. Push рабочих веток и PR выполняются по явному разрешению пользователя. После интеграции Канат указывает проверенный SHA в отчёте и отдельно перепроверяет исправления.
