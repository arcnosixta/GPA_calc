# ScholarPath — проверка UI по чек-листу Каната

Дата: 28 октября 2026, Asia/Qyzylorda. Проверка выполнена по поручению Каната (Qanat Qalmurzayev).

Проверенная версия: `main`, коммит `a3efe768bf74e665bd508b887a7490c7d7609c1d` («Управление»), после интеграции студенческих страниц и управления. Исходники приложения, данные, зависимости и конфигурация при проверке не изменялись.

## Результат

UI можно демонстрировать в проверенной среде. В воспроизведённых сценариях ошибок не обнаружено: 30 браузерных сценариев прошли, включая 20 сочетаний маршрута и ширины окна. Ошибок JavaScript и сообщений уровня error в консоли во время проверки нет. На всех четырёх маршрутах полноценный интерфейс, заглушек нет.

Это проверка UI-прототипа с демоданными, а не подтверждение готовности MVP. Регистрация, авторизация, реальные права, БД, API, сохранение и вычисления GPA не проверялись и не требуются на этом этапе. Отдельное подтверждение линтера и сборки Куралом перед командной приёмкой остаётся за Куралом; ниже зафиксирован фактический локальный запуск команд агентом.

## Среда и способ проверки

- Windows, Google Chrome `156.0.8078.49`, headless, production-сборка Next.js `16.4.2`.
- Локальный сервер: `npm start -- --port 3001`, адрес `http://localhost:3001`.
- Окна: **320×900, 360×900, 768×900, 1024×900, 1440×900 CSS px**.
- Чек-лист: [docs/qa.md](qa.md). Действия в браузере выполнены агентом через Playwright; скриншоты всех 20 сочетаний маршрута и размера просмотрены визуально. Дополнительно просмотрены форма с ошибкой и предпросмотр длинного названия на 320 px.
- Tab и Shift+Tab проверены на всех четырёх страницах при 320 и 1440 px; Enter — на ссылках и кнопке меню, Space — на выборе предмета, Escape — в мобильном меню, ArrowRight — для прокрутки таблицы.
- Реальные телефоны, другие браузеры, экранный диктор и увеличение масштаба отдельно не проверялись. Проверка подписей и ARIA не заменяет полный аудит доступности.

## Размеры и меню

- [x] Заголовки, пояснения, подписи полей и кнопки не перекрываются; карточки и формы перестраиваются.
- [x] Ни один из 20 вариантов не расширяет всю страницу: `documentElement.scrollWidth <= innerWidth`.
- [x] Длинное название предмета длиной 120 символов и код без пробелов не расширяют предпросмотр на 320 px.
- [x] Мобильное меню открывается и закрывается кнопкой, поддерживает переходы во все четыре раздела.
- [x] После выбора раздела меню скрывается; содержимое доступно для взаимодействия, невидимого перекрывающего слоя нет.
- [x] На 1024 и 1440 px боковая навигация не накладывается на содержимое.

Таблица каталога на узком экране шире своего контейнера и прокручивается внутри него. На 320 px проверена прокрутка вправо с клавиатуры после фокуса на таблице. Сокращённый текст выбранной программы в нативном `select` на телефоне дублируется полной подписью под полем.

## Клавиатура и формы

- [x] Tab и Shift+Tab перемещают фокус по доступным элементам в понятном порядке. У проверенных элементов видимая обводка фокуса.
- [x] Кнопка меню с иконкой имеет название «Открыть меню» / «Закрыть меню»; остальные действия подписаны текстом.
- [x] Enter активирует ссылки и кнопку меню; Space меняет выбор предмета. Непредусмотренной отправки формы в проверенных действиях нет.
- [x] Escape закрывает раскрытое мобильное меню и возвращает фокус на кнопку. Диалогов в текущем UI нет.
- [x] У всех `input` и `select` в содержимом страниц есть связанные подписи. Редактирование оценок не реализовано и не требуется.
- [x] `aria-describedby` указывает на существующие подсказки. При пустой отправке формы четыре обязательных поля получают текстовые ошибки и `aria-invalid`; фокус переходит на первое неверное поле.
- [x] Выборы и фильтры дают ожидаемый результат, отсутствие предметов объяснено отдельным состоянием.

В форме управления проверены пустые обязательные поля, название из пробелов, кредиты `-1`, `0`, `1.5`, `31` (ошибки) и граничные `1`, `30` (валидны). После правки значения ошибка соответствующего поля снимается; некорректная отправка не создаёт предпросмотр. Дополнительные скриншоты: [ошибка кредитов на 320 px](qa-evidence/2026-10-28/management-validation-320.png), [длинное название и код в предпросмотре на 320 px](qa-evidence/2026-10-28/management-long-title-320.png).

- [x] Настройка прямо предупреждает, что выбор не переносится; переход в «Мои предметы» действительно открывает исходный демоплан.

Дополнительно воспроизведены:

1. Настройка: группа ВТ-24-1 в третьем семестре даёт два предмета и семь кредитов; второй семестр показывает пустое состояние.
2. Самостоятельный план: выбор математики и «Введения в разработку» из разных семестров даёт два предмета и восемь кредитов; сброс очищает набор.
3. Каталог: поиск ` mAt 201 ` находит математику без учёта регистра и крайних пробелов; фильтр группы ВТ-24-1 даёт два предмета; первый семестр — один. Несовместимые фильтры и отсутствующая строка поиска дают пустое состояние. Сброс возвращает шесть предметов.
4. Форма: валидные данные создают только локальный предпросмотр. Изменение поля убирает устаревший результат; необязательный код может отсутствовать. Очистка сбрасывает поля. Каталог остаётся из шести предметов, после обновления новый предмет не появляется.
