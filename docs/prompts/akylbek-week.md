## Сделай студенческий путь

1. На `/dashboard` («Главная») используй профиль активной демосессии, список личных предметов и согласованные показатели. Курал выводит диалог первого входа на этом маршруте. После его завершения «Главная» должна использовать заполненные имя, фамилию, вуз и группу.
2. На `/profile` («Личный кабинет») покажи сохранённые поля профиля. Вуз и группу сопоставляй по ID с общими данными. В компонентах различай загрузку состояния, отсутствие сессии и отсутствие профиля.
3. На `/subjects` покажи личный план, оценки, семестр и кредиты. Дай студенту вводить и менять собственные буквенные оценки локально. Предмет без оценки помечай «Без оценки». Кредиты каталога доступны для чтения. Сохраняй текущий UI выбора группы или предметов на `/setup` как дополнительный путь.
4. Подключи `useDemoCatalog()` от Койшымана для текущих вариантов учебного плана. Согласуй порядок интеграции: начальные данные находятся в `@/lib/demo-data`, в итоговом сценарии варианты берутся из общего клиентского каталога. Оценки и зафиксированные кредиты студента принадлежат личному плану. Подключи один расчёт GPA для сводки «Главной» и личных предметов. Раздели общий GPA и GPA выбранного семестра. Показывай кредиты в плане, с оценкой и зачтённые. При отсутствии оценок показывай «—».
5. Покажи до двух предметов с оценками ниже B+, начиная с самой низкой. Предметы без оценки вынеси в отдельное состояние. Покажи прогноз отдельно от текущего GPA. Пользователь видит исходные оценки и кредиты, явно задаёт предположения по будущим оценкам и видит прогноз с этими предположениями. Временный сценарий сохраняет исходные оценки и кредиты личного плана. Для незаполненного сценария есть понятное состояние.

`@/lib/demo-session` экспортирует `useDemoSession()` со значениями `undefined` при восстановлении, `null` без сессии и `{ role, profile }` в активной сессии. Профиль равен `null` либо `{ firstName, lastName, universityId, groupId }`. Для согласованного локального редактирования используй `saveDemoProfile(profile)`. `demoUniversities` из `@/lib/demo-data` содержит ID и названия вузов. У `demoGroups` есть `universityId`. Сессия восстанавливается в текущей вкладке, явный выход и новый вход очищают старый профиль.

Канат поставляет `calculateGpa(subjects: readonly { credits: number; grade: Grade | null }[]): number | null` и `gradePoints: Record<Grade, number>` из `@/lib/gpa`. Согласуй порядок интеграции до импорта. Пока ветка Каната готовится, можно закончить компоненты и их состояния на статических данных. В итоговом коммите используй общий модуль. Держи расчёт в одном месте. Для базового примера A на 3 кредита, B на 2 и предмета без оценки на 3 результат `3.60`, кредиты 8/5/5. F участвует в GPA и кредитах с оценкой. Для зачтённых кредитов F исключается. Округляй только отображение.
