# ScholarPath — техническое описание проекта

ScholarPath — учебное веб-приложение для ведения личного плана, выставления оценок и расчёта GPA. Интерфейс написан на TypeScript с React, Next.js App Router и Tailwind CSS. Текущая версия работает с демоданными и хранит изменения в браузере. [Конфигурация проекта](package.json) · [Демо на Vercel](https://scholarpath-gpa.vercel.app)

## 1. Страницы и структура кода

Названия маршрутов, ссылки для навигации и правила доступа деморолей собраны в одном реестре. [site-routes.ts](src/lib/site-routes.ts)

## 2. Как сохраняются данные в браузере

Хранилище реализует функция `createBrowserStore`. При чтении она разбирает и проверяет JSON, а после изменения записывает новый снимок в `localStorage`. React-компоненты подписываются на изменения через `useSyncExternalStore`. Событие `storage` обновляет открытые вкладки того же сайта. Если браузер блокирует доступ к хранилищу, данные текущего сеанса остаются в памяти до перезагрузки. [browser-store.ts](src/lib/browser-store.ts)

| Ключ в `localStorage` | Что хранится | Модуль |
| --- | --- | --- |
| `scholarpath.demo-session.v2` | Активный email и роль, а также профили по email с именем, фамилией, вузом и группой. | [demo-session.ts](src/lib/demo-session.ts) |
| `scholarpath.student-progress.v1` | Для каждого email отдельно хранятся учебный план с оценками, баллы контролей по предметам, прогноз и выбранный календарь. | [personal-plan.ts](src/components/student/personal-plan.ts) |
| `scholarpath.demo-catalog.v1` | Общий для демопрофилей каталог в этом браузере. Содержит справочники, активные и архивные предметы, планы групп и настройки деморолей. | [demo-catalog.ts](src/lib/demo-catalog.ts) |

- При входе email приводится к нижнему регистру, пробелы по краям убираются. Выход очищает активный сеанс. При следующем входе с тем же email восстанавливаются профиль, план и оценки.
- При отсутствии записи в `localStorage` хранилище может перенести валидные данные прежнего сеанса и каталога из `sessionStorage`. Старый сеанс привязывается к демопрофилю `student@example.com`.
- Данные привязаны к профилю браузера и адресу сайта. Локальный запуск и Vercel имеют отдельные хранилища. Ключи можно посмотреть в инструментах разработчика в разделе **Application → Local Storage**.

## 3. Учебный план, страницы предметов и GPA

При первом обращении к личному плану `usePersonalPlan` собирает его по группе профиля из каталога и сохраняет копии предметов. Экран `/setup` добавляет выбранные предметы без оценки и пропускает дубли по ID. Для уже добавленного предмета расчёт GPA берёт кредиты из сохранённой копии и личную оценку. [Личный план](src/components/student/personal-plan.ts) · [Выбор предметов](src/components/student/plan-setup.tsx)

Название предмета в «Моих предметах» и в личном плане на главной ведёт на URL вида `/subjects/math`. Маршрут получает `subjectId` из URL, а клиентский компонент ищет его в личном плане текущего профиля. Если такого предмета в плане нет, открывается экран «Предмет не найден» со ссылкой на список. Список и отдельная страница используют одну форму оценки и записывают изменения через `setGrade`. [Ссылки в списке плана](src/components/student/study-plan-list.tsx) · [Форма оценки](src/components/student/subject-grade-field.tsx)

| Показатель | Правило расчёта |
| --- | --- |
| GPA по предмету | Балл выбранной буквенной оценки по шкале от 0 до 4. Например, `A− = 3.67`, `FX = 0.50`, `F = 0.00`. |
| Взвешенные баллы предмета | Балл оценки умножается на число кредитов предмета. |
| GPA семестра или общий GPA | Сумма взвешенных баллов делится на сумму кредитов предметов с оценками за выбранный семестр или за весь план. |
| Вклад предмета в общий GPA | Взвешенные баллы предмета делятся на сумму кредитов всех оценённых предметов плана. |

Предметы без оценки пропускаются при расчёте GPA. Оценки `FX` и `F` участвуют в GPA, зачтённые кредиты начисляются за оценки от A до D. Если оценок пока нет, сводка показывает «—». Для оценки `A` на 3 кредита и `B` на 2 кредита общий GPA равен `(4 × 3 + 3 × 2) / 5 = 3.60`. При замене первой оценки на `F` он станет `1.20`. [Шкала и формула](src/components/student/integration-adapter.ts) · [Сводка GPA и кредитов](src/components/student/student-summary.tsx) · [Приказ № 595](https://www.gov.kz/org/control/documents/details/39111?lang=ru)

Прогноз на главной берёт сохранённые предположения, подставляет их в копию плана и считает GPA той же формулой. Фактические оценки хранятся отдельно. [grade-forecast.tsx](src/components/student/grade-forecast.tsx)

### Академический календарь

На главной отображаются осенний и весенний семестры выбранного курса и по два рубежных контроля в каждом. В ориентировочном шаблоне это 7-я и 14-я недели. Также доступны опубликованные варианты Yessenov University (7-я и 15-я недели) и Университета Букетова (6–8-я и 12–14-я недели). Выбор шаблона сохраняется в браузере. [Код календаря](src/components/student/academic-calendar.tsx) · [Календарь Yessenov University](https://yu.edu.kz/ru/akademicheskij-kalendar/) · [Правила оценивания Университета Букетова](https://buketov.edu.kz/ru/page/for_teaching_students)

Страница предмета хранит баллы РК1, РК2 и экзамена отдельно. В поле «Итоговый балл по ведомости» вводится целое число от 0 до 100. Приложение переводит его в буквенную оценку по общей шкале, и эта оценка обновляет GPA. Итоговую букву также можно выбрать вручную. При изменении буквы вручную ранее введённый итоговый балл очищается. Баллы контролей и экзамена используются как личные записи, поскольку веса и допуск определяются правилами вуза и силлабусом. [Форма баллов](src/components/student/subject-assessment-form.tsx) · [Хранилище плана](src/components/student/personal-plan.ts)

## 4. Каталог и демороли

Начальные вузы, группы, предметы и список буквенных оценок определены в `demo-data.ts`. Модуль `demo-catalog.ts` проверяет изменения каталога и связывает предметы с группами и семестрами. Этот же каталог читают настройка профиля и экран выбора плана. Администратор управляет всем каталогом и демопользователями, модератор — справочниками в своей области. Архив успеваемости доступен всем деморолям. [Демоданные](src/lib/demo-data.ts) · [Компоненты управления](src/components/management)

## 5. Как запустить и проверить

```powershell
npm ci
npm run dev
```

Локальный сайт открывается на `http://localhost:3000`. Для проверки войдите как студент и при первой настройке выберите Центральный технический университет и группу ИС-24-1. В «Моих предметах» откройте «Математику», измените оценку и перезагрузите страницу. Проверьте общий GPA на главной, затем выйдите и войдите с тем же email, чтобы убедиться, что оценка сохранена.

```powershell
npm run lint
npm run build
node --test scripts/site-routes.test.mjs src/components/student/gpa.test.mjs
```

При запущенном сервере можно добавить HTTP-проверку маршрутов, задав в PowerShell `$env:SCHOLARPATH_CHECK_URL = 'http://localhost:3000'` перед запуском тестов. Сценарии входа, перезагрузки, повторного входа, переходов и адаптивности проверяет отдельный браузерный скрипт. [Тесты маршрутов](scripts/site-routes.test.mjs) · [Тесты GPA](src/components/student/gpa.test.mjs) · [Браузерная проверка](src/components/student/browser-check.mjs)
