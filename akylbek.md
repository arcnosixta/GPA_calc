# Акылбек — студенческий frontend

Дата: 4 ноября 2026 года. Задание: `docs/prompts/akylbek-week.md`.
Базовый SHA: `3314a8e065c4378a3e2dbdce7e6a98fdb8e2b52e`.
По прямому указанию пользователя работа коммитится в `main`; общие файлы других участников не меняются.

## Реализовано

- Главная использует имя, фамилию, вуз и группу активной демосессии. Профиль различает восстановление, отсутствие сессии и незаполненный профиль.
- Личные оценки редактируются в «Моих предметах» и используются на главной при переходах внутри приложения. Общий GPA отделён от GPA выбранного семестра. Кредиты показаны отдельно: в плане, с оценкой, зачтённые. F входит в GPA и кредиты с оценкой, но не в зачтённые. Без оценок GPA — «—».
- На главной показаны до двух оценок ниже B+, начиная с самой низкой. Предметы без оценки показаны отдельно.
- Прогноз содержит явные предположения, исходные оценки и кредиты. Он не изменяет личный план. Предметы без оценки и предположения исключаются с пояснением; пустой сценарий объяснён.
- `/setup` сохраняет выбор группы и ручной выбор, добавляет новые предметы в локальный план без повторов. Уже внесённые оценки и кредиты сохраняются; новые предметы добавляются без оценки. Выбор группы каталога не меняет профиль.

## Ограничения и передача Куралу

В базовом main нет `src/lib/gpa.ts` Каната и `src/lib/demo-catalog.ts` Койшымана.
Пользователь отдельно указал менять только файлы Акылбека. Поэтому интерфейс работает через временный `student/integration-adapter.ts`: один расчёт по шкале README и начальный каталог из `demo-data`. После передачи общих модулей заменить импорты адаптера на `@/lib/gpa` и `@/lib/demo-catalog`, убрать временные реализации и повторить проверки. Подключение живого каталога управления пока не выполнено.
